CHANGELOG — H&S HOME SOLUTIONS

2.0.0 (23 Oct 2026) — Next.js + Supabase
- Converted static HTML/CSS/JS site to Next.js 14 (App Router, TypeScript); original design preserved.
- Added Supabase database (categories, products, orders, order_items, site_settings, admins) with RLS.
- Added secure order function create_order(): prices read from DB, optional stock tracking.
- Added admin panel (/admin): dashboard, orders, products + image upload, categories, customers, settings.
- Checkout now saves orders, then opens WhatsApp with the order number.
- Old static files moved to legacy/.

1.x — static storefront with 12 shortlisted products, WhatsApp checkout (see legacy/).
